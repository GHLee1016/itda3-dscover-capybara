# EDA 11 — 인접 박스 병합 + 느슨한 자릿수 패턴

- 대상: 03단계에서 이미 저장한 OCR 결과 **500장** (0°·90°)
- **추가 OCR 없음 → 추론 비용 증가 0**

10단계 오라클 실험에서 확인한 두 가지 손실을 후처리로 되돌린다.

| 사례 | OCR 출력 | 원인 |
| --- | --- | --- |
| `002401` | `'20221'` + `'104'` | det 가 날짜 한 줄을 두 박스로 분할 |
| `001201` | `'2022716'` | `2022.07.16` 에서 `07` 의 0 이 탈락 |

## 결과

| 방식 | coverage | Δ | plausible | 이미지당 후보 |
| --- | ---: | ---: | ---: | ---: |
| A. 현재 (박스별 엄격 파싱) | **43.8%** | +0.0%p | 91.8% | 0.49 |
| B. + 인접 박스 병합 | **51.0%** | +7.2%p | 91.6% | 0.57 |
| C. + 7자리 느슨 패턴 | **45.8%** | +2.0%p | 90.8% | 0.52 |
| D. 병합 + 느슨 (둘 다) | **52.8%** | +9.0%p | 90.5% | 0.61 |

## 육안 정답 검증

| 파일 | 정답 | A 현재 | B 병합 | C 느슨 | D 둘다 |
| --- | --- | :-: | :-: | :-: | :-: |
| `000001.jpg` | 2027-06-26 | O | O | O | O |
| **합계** | | **1/1** | **1/1** | **1/1** | **1/1** |

> 정답셋 1장만 표본에 포함되어 있다 (500장 층화표본과 겹치는 만큼).

> **D. 병합 + 느슨 (둘 다)** 가 coverage **52.8%** 로 최고 (+9.0%p). plausible 은 91.8% → 90.5%.
>
> plausible 이 크게 떨어지지 않는다면 순수 이득이다 — **추론 비용이 0**이므로 CPU 예산에 영향을 주지 않는다.
