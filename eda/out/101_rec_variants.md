# EDA 101 — 인식기를 바꾸면 상한이 오르는가

검출기 쪽은 상한에 닿았다(EDA 99·100). 남은 오답의 대부분이
"글자를 못 만드는" 경우이므로 인식기를 본다.

- 라벨 580장 (홀드아웃4 는 최종 판정 전용이라 제외)
- det 는 small@1024 로 고정하고 rec 만 바꿨다

## 인식기별 단독 성능

| 인식기 | 필드 정확도 | 완전일치 | 장당(병렬) |
| --- | ---: | ---: | ---: |
| rec_small (현재) | 86.8% | 84.7% | 1.82초 |
| rec_medium | 87.0% | 85.3% | 4.26초 |
| rec_korean | 74.3% | 70.9% | 1.90초 |
| rec_en | 75.7% | 72.2% | 1.80초 |

## 상한

| | 필드 정확도 | 완전일치 |
| --- | ---: | ---: |
| 현재 인식기 단독 | 86.8% | 84.7% |
| **네 인식기 오라클 상한** | **89.4%** | 88.1% |

## 계단으로 붙였을 때 (실패분에만 다음 인식기)

| 구성 | 필드 정확도 | 완전일치 |
| --- | ---: | ---: |
| 현재 하나만 | **86.8%** | 84.7% |
| + rec_medium | **88.5%** | 86.6% |
| + rec_korean | **87.6%** | 85.7% |
| + rec_en | **87.8%** | 85.9% |
| + medium + korean | **88.6%** | 86.7% |
| + 셋 다 | **88.9%** | 87.1% |

## 판단

오라클 상한이 +2.6%p 남아 있고, 계단으로 붙이면
**+ 셋 다** 가 +2.0%p 를 가져온다.

이 수치는 오염된 표본에서 나온 것이므로, 채택하려면 새 표본이 필요하다.
